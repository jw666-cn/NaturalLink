# 自然衔接 · NaturalLink

> 把任何内容，翻译成 AI 最容易理解的形式。

**NaturalLink** 是一个通用多模态转化引擎：任何输入（画面/文档/视频/音频/表格/代码/网页）→ 对当前大脑模型最优、最省 token 的形态。它源自「AI 虚拟仿生视网膜」的视神经层（OpticNerve），现已独立为通用转化引擎。

## 它解决什么

AI 大模型（尤其是视觉模型）不是"给什么看什么都懂"——原始输入往往又大又杂，浪费 token 还看不清。NaturalLink 在"输入 → 大脑"之间加一层**转化引擎**，像视神经一样，先把内容翻译成大脑最容易懂的形态：

```
任何输入 → NaturalLink 转化 → 对大脑最优的表示 → 你的大脑(模型)
```

## 核心能力（内容类型覆盖）

| 内容类型 | 转化输出（对 AI 最优形态） |
|---|---|
| 视觉画面帧 | 增强像素 + 稀疏编码 + 元信息（省 token、看清小字） |
| 文档（PDF/Word/PPT/Excel/邮件/EPUB/HTML） | Markdown（省 token、锁结构） |
| 表格 / CSV / 结构化数据 | 结构化表示（不丢行列关系） |
| 视频 | 关键帧采样 + 抽帧 + 转写 |
| 代码 | 结构化 / 高亮 |
| 网页 / URL | Markdown + 结构化 |

## 三大卖点

1. **看得清**：画面增强 + 小字超分 + 局部对比度，可读性可提升数倍
2. **看得省**：稀疏编码 + token 预算，token 可降 30%–40%（永不比原帧贵）
3. **不绑定**：插件化转换器架构，任何新内容 = 新增一个 converter，引擎本体不动；输出喂给任何大脑模型

## 架构

插件化转换器框架（继承开源 MarkItDown 的设计思路并扩展）：

- `DocumentConverter` 抽象基类（`accepts` / `convert`）
- `register_converter` 插件式注册、优先级稳定排序
- 自动类型识别
- 结果类型四种：`markdown / image(增强帧) / structured / frame(关键帧)`

画面走 `VisionConverter` 五步：前景检测 → XY-Cut 分块 → 稀疏选块 → 小字超分增强 → 拼图压 token。预算让步「先降超分 → 再整体缩 → 最后才丢冗余块」，硬上限=整帧基线。

## 实测数据

| 输入场景 | 原 token | 输出 | 比率 | 结果 |
|---|---|---|---|---|
| 桌面 1280×800 | 576 | 353 | **0.61×** | 3/3 内容块保留 |
| 小字低对比 | 159 | 131 | 0.82× | **可读性 ×3.7** |
| 整页文本 1000×700 | 476 | 337 | 0.71× | 13/13 块保留 |
| 随机噪声/纯色 | 394 | 394 | 1.00× | 自动整帧，不降级 |
| 流式 3 帧 | 952 | 674 | 0.71× | 重复帧去重 |

## 快速开始

```bash
pip install -r requirements.txt
```

```python
from naturallink import NaturalLink

nl = NaturalLink()
result = nl.convert("输入路径或帧")   # 自动识别类型并转化
print(result.markdown)                # 或 result.image / result.structured
```

## 技术栈

Python · numpy · pillow；插件化转换器框架；增量 / 稀疏编码 / XY-Cut 分块 / 小字超分。

## 边界（诚实说明）

- 不是 Agent，只负责"转化"，理解交给大脑模型
- 多彩壁纸/照片等复杂前景会**保守回退整帧**（宁不多省，不切错）
- 视频转写依赖可选回调，关键帧采样已实现
- 依赖模型定位的变焦、VLM 数值幻觉等属大脑侧边界
